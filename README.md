# Paila — secure offline payment system

**Money moves. Even with zero bars.** Get the app: **https://github.com/limitlessneverdies/paila-app/releases/latest**

Paila signs single-use payment notes on-device and delivers them by **QR, Bluetooth, Wi-Fi Direct or NFC** — settling exactly once when back online. Made by **Bishowdeep Bhusal**.
